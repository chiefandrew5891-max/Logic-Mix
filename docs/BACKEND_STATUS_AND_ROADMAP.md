# Backend: состояние и план (LogicMIX-backend, `feature/stage-2`)

Аудит по фактическому коду; прежние отчёты частично устарели. Тесты: `PYTHONPATH=src pytest` — **34 passed** (29 прежних + 5 новых).

## 1. Полностью реализовано (локально, подтверждено тестами)
- Ядро: модели/статусы, нормализация (языки, ё→е, blocklist), SQLite-хранилище, пайплайн импорта/слияния, реестр источников с блокировкой неутверждённых лицензий.
- Hunspell (spylls) + wordfreq → частотные списки en (16 253) и ru (18 233).
- Пакеты: gzip JSON schema 1, манифест, SHA-256, неизменяемые имена, публикация «манифест последним», история и откат, dataVersion только растёт.
- Android `core/content/PackSync.kt` + `ContentSyncWorker` (WorkManager): проверка SHA-256, атомарная установка, закрепление версии для активной игры.
- Новое: серверный план ежедневных испытаний (см. `DAILY_CHALLENGES.md`).

## 2. Реализовано частично
- Адаптеры Kaikki/Wikidata: код и тесты на fixtures есть, **реальных выгрузок нет** (`work/raw` содержит только Hunspell).
- Пакеты Mini Crossword (нужны определения Kaikki) и Word Logic (нужны отношения Wikidata) — без реальных данных не собираются; фиктивные не создавались.
- Cloud Run Job, Dockerfile, scheduler, правила Firestore/Storage — **шаблоны**, не развёрнуты.
- Ежедневные испытания: сервер (план+публикация) готов, клиент нет; валидаторов решаемости нет.

## 3. Не реализовано
Подключение скачанных пакетов к Android-генераторам (`PackStore.activeRows` нигде не вызывается); серверный URL в приложении; словари uk/it/de/fr/es/zh-CN; юридически подтверждённые лицензии; Firestore/Storage в облаке; Cloud Function проверки результатов; интеграционные HTTP-тесты.

## 4. Не протестировано
Реальный GCS (`GcsObjectStore`), Docker-образ, Cloud Run/Scheduler, WorkManager на устройстве, Android-сборка (Gradle недоступен), сетевая загрузка Kaikki/Wikidata.

## 5. Блокеры
1. Лицензии: Kaikki/Wiktionary и данные wordfreq — CC BY-SA (ShareAlike), Hunspell-словари — отдельные лицензии; все `needs_review`, production заблокирован кодом.
2. Нет серверного URL/бакета и решения владельца о развёртывании (расходы).
3. Нет Python-портов генераторов головоломок → невозможна серверная проверка решаемости.

## 6. Изменения в этом задании

## 9. Ориентировочные расходы (оценка, тарифы с сайта не проверялись — сверить перед запуском)
