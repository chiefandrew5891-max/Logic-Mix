# Награды и достижения: предложение для обсуждения

**Статус: только концепция. Ничего не реализовано**, идентификаторы Play Games Achievements не создавались, экономика не менялась. Ждём утверждения владельца.

## 1. Исходные данные (что реально есть)
- 9 категорий, режимы Career/Daily/Endless/Arcade; единый XP (`XpConfig`, `ProgressRepository`, один раз за `puzzleId`), уровни 1–99, серия дней (`observeStreak`), Arcade (`ArcadeStats.bestScore`), рекорды Lines (`OrbStore.best`) и Two Dots (`TwoDotsStore.best` по режимам), бонусные слова филвордов, подсказки (`hintsUsed`), Google Play Games (11 таблиц, вход необязателен).
- **Ограничение:** XP по шести категориям до версии `d218af4` не восстановить. Поэтому достижения считаются **только по сохранённой статистике**: таблица попыток Room (число решённых заданий; категорию по ним надёжно определить нельзя) + `games_category_xp` (с момента его появления). Ретро-выдача допускается только там, где есть подтверждённые данные: уровень/общий XP, серия, best Lines/Two Dots/Arcade. Остальное копится с нуля — честно показывать «с момента обновления».

## 2. Разделение сущностей (чтобы не дублировали друг друга)
| Сущность | Смысл | Где живёт |
|---|---|---|
| **Значок** (badge) | Единовременный факт («сделал X»), коллекция | экран Наград |
| **Медаль** (bronze/silver/gold/platinum) | Ступень **накопительного** пути в одной теме (количество) | у значка-пути |
| **Звёзды** (1–3) | Качество **одного** прохождения (без подсказок, быстро, без ошибок); не накапливаются в валюту | на карточке задания |
| **Кубок** | Редкая «вершина» коллекции: платиновая медаль пути или мастерство категории | витрина |
| **Уровень игрока** | Общий прогресс; единственное событие с большой фанфарой | существует |
Новых валют нет: награда = XP (малый, в централизованном конфиге) либо только статус. Большие фанфары — только Level Up; достижение — компактный тост «+N XP».

## 4. Звёзды качества (не достижения)
1★ — решено; 2★ — без подсказок; 3★ — без подсказок и без ошибок/сброса (определение для каждой категории согласовать). Хранятся локально на `puzzleId`, XP не дают (чтобы не удваивать систему XP); служат метрикой для значков 2, 14, 21.

## 5. Архитектура и Google Play Games Achievements
- Новый чистый домен `domain/achievements`: определения (id, ступени, метрика, порог, XP) → `AchievementEngine.evaluate(stats): List<Unlock>`; события игры лишь обновляют статистику (не дублируя XP).
- Хранение: Room-таблица `achievement_progress(id, value, unlockedTierMask, unlockedAt, xpPaid, gpgSyncedValue)` + миграция без потерь; **XP за достижение платится один раз** по `(id, tier)` внутри той же транзакции (`xpPaid`), через общий `ProgressRepository` (тот же журнал, что и задания) → нет двойного начисления.
- Гости/оффлайн: всё считается локально, вход в PGS не нужен.
- Синхронизация: `GamesCoordinator` (существующий) после входа отправляет `unlock` для standard и `setSteps` для incremental (значения монотонные → идемпотентно); `gpgSyncedValue` фиксирует подтверждённое. Выдача в GPG не даёт XP повторно.
- Идентификаторы: `assets/games/achievements.properties` (как `leaderboards.properties`); пустой ID → достижение остаётся локальным, ошибок нет.
- Существующие игроки: Ретро-выдача по подтверждённым данным (level/XP, streak, bestScore/Lines/Two Dots, число решённых заданий из Room); счётчики категорий и бонусных слов стартуют с момента обновления. **Ретро-XP не начислять** (только статус), чтобы не изменить экономику.

## 6. Интерфейс экрана «Награды» (использует `BrandFooter` в конце страницы)
Верх: сводка (получено X/24, кубки, ближайшее достижение). Вкладки/секции: «Путь», «Категории», «Arcade и рекорды», «Ежедневные», «Секретные». Карточка: значок, название, прогресс-бар, медальная ступень, редкость (цвет рамки), дата. Заблокированные — силуэт и условие. Витрина кубков/медалей сверху. Получение — компактный тост «+N XP» без фанфар и полноэкранной заставки; при уменьшении анимаций — без анимации. Светлая/тёмная темы, 8 языков.
